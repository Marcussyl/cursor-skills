# Grilling

Stress-test a plan, decision, or idea. Do this when the user wants that pressure test, or uses any grill trigger phrase.

Work from a design tree. Each round asks the current frontier questions. Number each question and include a suggested answer.

- Look up facts yourself.
- Leave decisions to the user.
- Do not start executing until the frontier is empty and both sides share the same understanding.
