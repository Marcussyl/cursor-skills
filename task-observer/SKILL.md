# Task observer

Load this before the first tool call of a session, and before writing or proposing a plan. Any turn that will use a tool counts.

Also use it during multi-step work, after the task when discussing feedback, and when the user mentions the observation log, skill taxonomy, or "One Skill to Rule Them All".

Watch for patterns, corrections, and methods worth keeping as a reusable skill. Write observations under the workspace folder `skill-observations/observation-log/`.
