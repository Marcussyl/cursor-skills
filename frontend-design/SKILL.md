# Frontend design

Use this when creating a new UI or reshaping an existing one, and the result needs a recognizable, intentional look.

Before writing code:

1. Set a color palette, type, and layout plan from the theme and the brief.
2. Check that the plan does not look like a default AI template.

Avoid these common generated looks:

- Cream background with terracotta accents.
- Acid green on a dark background.
- Newspaper columns.
- Generic identical cards.
